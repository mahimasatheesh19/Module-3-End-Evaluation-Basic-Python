# Module-3-End-Evaluation-Basic-Python
This assignment is about entries stored in a dictionary of lists, perform basic data cleaning, extract meaningful insights, and apply logic using loops, conditionals, string operations, and user-defined functions.
1. Created a dictionary containing 10 preloaded feedbacks with s_no, name, feedback and rating.
2. Asked the user to add feedbacks how many they wanted by collecting name, feedback and rating while s_no generated automatically. New feedbacks were appended to the existing dictionary.
3. Removed punctuation marks, extra spaces and converted all feedback texts into lower case.
4. To count the number of feedback entries containing the words "good", "poor", "excellent" created a function count_word_in_feedbacks(word).
5. As the final step displayed the final cleaned feedback dictionary, calculated average rating, find the longest comment, displayed unique words and sorted feedbacks by rating from highest to lowest using zip() and sorted().
*Dictionary and lists, loops, functions, lower(), replace(), split(), join(), append(),sets, built in functions sum(),len(),max(). lambda function, zip(), sorted() are the python concepts used in this assignment.
